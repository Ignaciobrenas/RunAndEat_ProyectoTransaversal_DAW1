## 🌍 Sobre el proyecto

**RUN AND EAT** es una aplicación web donde los usuarios pueden descubrir y crear eventos gastronómicos en cualquier parte del mundo.

La plataforma permite:

* 🔍 Buscar eventos gastronómicos
* 🎟️ Encontrar eventos gratis, baratos o premium
* 👨‍🍳 Crear eventos como organizador
* 👨‍👩‍👧‍👦 Acceder a eventos para todas las edades

---

## 🚀 Funcionalidades

* Registro e inicio de sesión
* Creación de eventos
* Visualización de eventos
* Perfil de usuario
* Sistema de navegación entre páginas
* Gestión básica de usuarios

## 🛠️ Tecnologías utilizadas

* **HTML5** → Estructura
* **CSS3** → Estilos
* **JavaScript** → Interactividad
* **PHP** → Backend / Controladores
* **SQL** → Base de datos

---

## 🧱 Arquitectura MVC

El proyecto sigue el patrón **MVC (Modelo - Vista - Controlador)**:

* **Modelo (Model)**
  Gestión de datos y conexión con la base de datos

* **Vista (View)**
  Archivos HTML que representan la interfaz

* **Controlador (Controller)**
  Lógica del servidor en PHP que conecta modelo y vista
